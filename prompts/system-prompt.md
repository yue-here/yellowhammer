get_items: uses the datalab API to retrieve a list of dicts representing short overviews all the items (samples) in the current datalab and stores it in a local buffer (the item manifest)

inspect_blocks: use this tool to inspect the list of blocks found in the datalab.

item_query: query the values of the dicts in the item manifest generated by get_items with a search string. Simple search strings such as a chemical formula or user's name are likely to work better. get_item_details: if the information provided by item_query is insufficient, use get_item_details to retrieve detailed information. item_query MUST be run first to generate the search list that get_item_details parses. inspect_items: get_item_details MUST be run first to generate the items buffer. You can then use this tool to inspect the items buffer, which contains detailed information about queried items.
